# 扩展层(Extensions)实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development.

**Goal:** 实现到账流水(§9)、Excel 批量导入(§10,含校验/预览/疑似重复)、统计分析(§11.3-11.5 自定义/月度/跨项目)。

**Architecture:** 到账仅记录参考;Excel 用 exceljs 解析,两阶段(上传校验→确认入库),ImportBatch/ImportRow 留痕;统计复用 ledger 公式实时聚合。

**Tech Stack:** exceljs、复用 lib/budget + services。

## Global Constraints(继承)

- 金额 Decimal(18,2)+decimal.js+字符串传输;主键 UUID v7;审计 recordAudit(tx) 同事务;服务端权限再校验。
- 到账不作预算上限(§9);Excel 一行一叶节点;疑似重复默认不导入可强制(§10.3)。

## Task 1: receipt.service.ts(§9) + API + page

**Files:** `src/server/services/receipt.service.ts`, `/api/projects/[id]/receipts/route.ts`, `src/app/(dashboard)/projects/[id]/receipts/page.tsx`

**Functions:**

- `createReceipt(projectId, {receiptDate, amount, summary, remark}, user)`: requirePermission('record:create') or a receipt action — reuse 'record:create' (§2.2 到账属业务维护); amount>0; recordAudit.
- `listReceipts(projectId, user)` + project cumulative sum.
- `updateReceipt`/`deleteReceipt`(逻辑删?— §9 允许修改;提供 delete).

**Tests:** create + list cumulative; update; permission (non-member 403).

**Page:** AntD Table(到账日期/金额/摘要/备注/录入人)+ 新增表单 + 项目到账累计。

## Task 2: Excel 导入解析+校验(§10.1/10.2) — service 阶段一

**Files:** `src/server/services/excelImport.service.ts`, `src/lib/excel/template.ts`(模板生成)

**Functions:**

- `parseAndValidate(fileBuffer, projectId, user)`: exceljs 解析;每行 → ImportRow(parsedData, validationStatus, errors);校验:项目编号存在、年度有效、科目编码是该项目叶节点、金额>0、业务状态合法、日期可解析。错误定位到 sheet+row+field(§10.2)。疑似重复(§10.3):按(项目+年度+科目+金额+业务日期+摘要)匹配已有 business_records → duplicateFlag=true。创建 ImportBatch(status='pending'),写 ImportRows,不写业务记录。返回 batchId 供预览。
- `getImportBatch(batchId, user)`: 返回有效行/错误行/疑似重复行分组,供预览页。

**Tests:** parse 合法文件→有效行;错误行定位;疑似重复识别;非叶科目→错误。

## Task 3: Excel 导入确认入库(§10) — service 阶段二 + API + page

**Files:** excelImport.service.ts(confirmImport), `/api/projects/[id]/imports/route.ts`(upload)+`/api/projects/[id]/imports/[batchId]/confirm/route.ts`, page `imports/page.tsx`

**Functions:**

- `confirmImport(batchId, selectedRowIds, user)`: 用户勾选的有效行(可含强制导入的重复行)→ 在事务内逐行创建 business_record(复用 businessRecord 逻辑或直写);超预算行允许(§10.2);强制导入的重复行 forcedImport=true 留痕(§10.3);batch status→'confirmed'。recordAudit。
- Upload route: multipart file → parseAndValidate → 返回 batchId。
- Confirm route: body {selectedRowIds} → confirmImport。

**Page:** 上传(Upload 组件)→ 预览页(三个分区:有效/错误/疑似重复,可勾选)→ 确认导入按钮。

**Tests:** confirm 创建业务记录;重复行不选则不导入;强制导入留痕 forcedImport。

## Task 4: 统计分析(§11.3-11.5)

**Files:** `src/server/services/statistics.service.ts`, `/api/statistics/*`

**Functions:**

- `customStatistics(filters, user)`: §11.3 组合筛选(项目/年度/科目/状态/日期范围/经办人/是否作废)→ 汇总(预算/已支出/应付未付/总占用/结余/执行率)+ 明细列表。复用 computeOccupancy。
- `monthlyHistory(projectId, year, user)`: §11.4 按业务发生日期归月,动态重算(直接查 records 按月 group)。
- `crossProjectStatistics(filters, user)`: §11.5 admin 跨项目汇总(同名科目不合并)。

**Tests:** customStatistics 筛选汇总正确;monthlyHistory 按月;crossProject 仅 admin。
