## Task 1: 跨年结转(§8.7) service + API

**Files:** `src/server/services/yearCarryover.service.ts`, `/api/projects/[id]/carryover/route.ts`

**Function** `carryOver(projectId, fromYear, toYear, user)`:

- requirePermission('record:create') (结转属业务维护)。
- 找出 fromYear 中状态非 PAID(PLACEHOLDER/CONTRACT/FINANCE_APPROVAL)且非作废的记录 → 对每条:在 toYear 同科目新建一条同金额同状态的业务记录(结转记录),原记录标记结转(可加 remark 或 history action:'carryover' + 原 id)。
- §8.7:若 toYear 对应科目不存在或其可用预算不足 → 该条预警(返回 warnings 列表),不静默丢失;记录仍创建(超预算允许,§8.4)但需人工确认(返回 warnings)。
- 事务内执行 + 审计。
- 返回 {carriedCount, warnings:[{originalRecordId, reason}]}.

**Tests:** 结转非 PAID 记录到新年度;PAID 不结转;toYear 缺科目→warning;原记录留痕(history)。
