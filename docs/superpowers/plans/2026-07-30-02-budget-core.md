# 预算核心层(Budget Core)实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development. Steps use checkbox syntax.

**Goal:** 实现项目管理、初始预算编制(含审批生效事务)、预算执行台账(实时聚合重算),跑通「项目→编制→占用→台账」核心闭环。

**Architecture:** Service 层(`src/server/services/`)封装业务规则 + Prisma 事务,Route Handler(`src/app/api/`)只做 HTTP 解析 + 鉴权 + 调 service;台账占用走 `lib/budget/` 公式库实时聚合;审批生效用事务保证原子性 + 审计同事务。

**Tech Stack:** Next.js Route Handlers、Prisma 事务、decimal.js、AntD 5、复用地基层全部产物。

## Global Constraints(继承地基层)

- 金额 Prisma Decimal(18,2) + decimal.js + JSON 字符串传输 + 前端只展示。
- 主键 UUID v7(`lib/id.ts` 的 `uuidv7()`)。
- 当前预算 = 初始 + 已生效调整增量(存储值);占用/执行率实时聚合重算。
- 审计走 `recordAudit(tx, ctx)`,必须在 `prisma.$transaction` 内调用(§14.2)。
- 鉴权:`requireUser()` 取当前用户 → `requirePermission(user, action, projectId?)`。
- 父节点金额只读,由叶节点上卷生成(调 `buildTreeRollup`)。
